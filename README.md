# Excalidraw для Пульса

Плагин платформы «Пульс»: доски [Excalidraw](https://github.com/excalidraw/excalidraw) (MIT) прямо в Пульсе.

- **Редактор** — `@excalidraw/excalidraw` 0.18.1, собранный статическим бандлом вместе со шрифтами: ничего не
  грузится с CDN. Открывается в «Файлах» (обработчик `*.excalidraw`, «Создать ▾ → Доска Excalidraw») и во всю
  вкладку — `/plugin-apps/excalidraw/editor` (список досок папки «Доски», новая доска, `?path=…`).
- **Автосохранение** — через `autosave_seconds` после правки (не позже 10 с), `Ctrl+S` — сразу; статус в углу и в
  панели «Файлов». Защита от потери: предупреждение при закрытии, попытка сохранить (`keepalive`), копия правок в
  браузере (`localStorage`) с предложением вернуть её при следующем открытии; конфликт версий (`If-Match`) не
  перетирает чужие правки — редактор сливает их и сохраняет снова.
- **Хранение** — обычные файлы `.excalidraw` (JSON Excalidraw, картинки внутри — `files` с dataURL) в каталоге
  владельца: их видят «Файлы», агенты, `pulse files`; прошлые версии хранит Пульс (`.file-versions`, 5 последних).
- **Агенты** — команды `pulse excalidraw list | get | create | add | update | delete | export | check`, скилл
  `skills/excalidraw.md`. Агент описывает доску словами, добавляет фигуры с подписями и стрелки между ними, правит и
  удаляет по id, выгружает PNG/SVG (серверная отрисовка, упрощённый стиль).
- **Живое обновление** — открытый редактор раз в 2 с сверяет версию файла; если файл изменил агент (или другая
  вкладка) — сливает по элементам (`web/src/merge.js`: трёхсторонне, относительно последней синхронизации) и
  показывает «Агент изменил элементы — Показать». Несохранённые правки владельца не теряются.
- **Чат напротив доски** — кнопка «Чат»: чат Пульса о файле доски (`/api/files/chats`), к сообщению дописывается
  путь доски и выделение; агент видит и то, что выделено сейчас (`pulse excalidraw get`).

## Устройство

```
pulse-plugin.json      манифест: embed + files:open + files, обработчик и шаблон .excalidraw, меню «Доски»
commands.json          команды агентов
skills/excalidraw.md   скилл для агентов
backend/excalidraw_plugin/
  app.py               процесс плагина: страница редактора, API страниц (/file/…, /presence, /boards), команды
  scene.py             доска как данные: описание, создание и правка элементов
  render.py            SVG/PNG без браузера
  static/              собранный редактор (build.sh) — в плагине готовым, сборка при установке не нужна
backend/tests/         pytest
web/                   исходники редактора (React + @excalidraw/excalidraw, Vite), merge.test.mjs
ui/                    страница меню (песочница): недавние доски, вход в редактор
templates/             пустая доска для «Создать ▾»
build.sh               сборка web/ → backend/excalidraw_plugin/static
```

**Почему редактор — встроенная страница (`embed`), а не страница меню.** Страницы меню живут в песочнице без
сессии владельца: оттуда нельзя открыть доску из «Файлов» или вести чат. Встроенная страница
(`/plugin-apps/excalidraw/…`) — того же адреса, что Пульс, и работает от имени владельца. С контракта плагинов 1.9
пункт меню «Доски» (`"app": "/editor"`) показывает редактор прямо на странице меню; Пульс без поддержки `menu[].app`
показывает запасную страницу `ui/` — список досок и кнопку «Открыть редактор» в новой вкладке. В «Файлах» редактор
встроен полностью в любой версии.

**Права.** `embed` — редактор работает встроенной страницей с сессией владельца (доски из «Файлов», чат рядом);
`files:open` — обработчик `*.excalidraw` и шаблон «Доска Excalidraw» в «Файлах»; `files` — команды агентов
читают и пишут доски, список досок хранится файлом в папке плагина. Сеть наружу плагину не нужна.

**Лицензии.** Код плагина — MIT (LICENSE). В `backend/excalidraw_plugin/static/` — собранный
[Excalidraw](https://github.com/excalidraw/excalidraw) (MIT) и его шрифты (лицензии — у шрифтов в пакете
`@excalidraw/excalidraw`: SIL OFL 1.1 и MIT).

## Сборка и тесты

```bash
./build.sh                                         # node 20+; node_modules — в /tmp/pulse-excalidraw-build
cd backend && PYTHONPATH=<pulse>/plugin_sdk:. python -m pytest tests
```

Установка: из каталога плагинов Пульса (Настройки → Плагины) или `pulse plugins install excalidraw`; из папки —
`pulse plugins install <путь к клону>`. Тесты без ядра: `pip install -r backend/requirements-dev.txt`,
`cd backend && python -m pytest -q`. Релиз — тег `vX.Y.Z` (CI собирает tar.gz и релиз), затем MR в
[pulse-plugins](https://github.com/pulse-assist/pulse-plugins).
