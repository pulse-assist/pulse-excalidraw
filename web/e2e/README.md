# Проверка редактора в браузере

Сценарии в настоящем Chromium (Playwright) против процесса плагина напрямую (`127.0.0.1:<порт плагина>`):

- `e2e.mjs` — доска из «Файлов» по билету: загрузка, рисование и автосохранение, правка агента «вживую» (тост
  «Агент добавил… — Показать»), одновременные правки владельца и агента (слияние), выделение видно агенту
  (`pulse excalidraw get`), закрытие вкладки с несохранённым (предупреждение и дозапись), нет запросов наружу (CDN).
- `e2e2.mjs` — редактор во всю вкладку: список досок, переключение досок без потерь, панель чата (API Пульса
  в браузере подменено).
- `ticket.py` — тестовый билет плагина на пробную доску (как выдаёт ядро при открытии в «Файлах»; `run_id`
  `xd-e2e-test` — потом удалить из `plugin_file_tickets`).

```bash
npm i playwright@1.56.1            # в отдельной папке, не в каталоге файлов
T=$(python ticket.py "excalidraw/тест/Доска А.excalidraw")
node e2e.mjs <порт плагина> "$T" "excalidraw/тест/Доска А.excalidraw"
```

На Ubuntu 26.04 Playwright берёт сборку для 24.04 (`PLAYWRIGHT_HOST_PLATFORM_OVERRIDE=ubuntu24.04-x64`), а
недостающие библиотеки (libatk, libatk-bridge, libatspi, libxdamage, libasound, libxres) можно не ставить в
систему: `apt-get download …`, `dpkg -x` в папку и `LD_LIBRARY_PATH`.
