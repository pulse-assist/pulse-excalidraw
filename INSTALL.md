# Установка плагина «Excalidraw» (доски)

Инструкция для агента Пульса после `pulse plugins install …`. Пройди её целиком.

## 1. Проверь, что плагин запустился

```bash
pulse plugins list            # у excalidraw — status: running
pulse excalidraw check        # редактор собран, шрифты локально, PNG рисуется
```

status: error — `pulse plugins logs excalidraw --lines 80`, расскажи владельцу, что в журнале, и остановись.
Нужен Пульс с контрактом плагинов 1.5+ (встроенные страницы `embed`, обработчики «Файлов», билеты файлов).

«Отрисовка PNG» не ok — на сервере нет системной libcairo: доски и редактор работают, `export --format svg` —
тоже; PNG появится, если администратор поставит `libcairo2` (Debian/Ubuntu) и плагин перезапустят.

## 2. Права — скажи владельцу

Плагин просит право **embed**: редактор встраивается в страницы Пульса (в «Файлы» и во вкладку редактора) с правами
владельца — так он сам открывает и сохраняет доски и ведёт чат о доске. Скажи прямо: «встраивается в интерфейс с
вашими правами — ставьте только тем плагинам, которым доверяете». Ещё права: **files:open** (открывать и сохранять
файлы досок, которые открываете вы или агенты) и **files** (своя папка `Plugins/Excalidraw` — туда команда `export`
кладёт картинки).

## 3. Настройки (по желанию владельца)

```bash
pulse plugins get excalidraw                               # схема настроек
pulse plugins settings excalidraw set folder="Доски"       # папка досок в «Файлах» (по умолчанию «Доски»)
pulse plugins settings excalidraw set autosave_seconds=2   # пауза автосохранения
pulse plugins settings excalidraw set chat_panel=true      # чат с агентом рядом с доской
```

Папку досок заранее создавать не нужно: редактор создаст её с первой доской.

## 4. Проверь на пробной доске

```bash
pulse files ls Доски || pulse files mkdir Доски
pulse excalidraw create --file "Доски/Проверка плагина.excalidraw" \
  --elements '[{"id":"a","type":"rectangle","text":"Пульс","fill":"blue"},{"id":"b","type":"ellipse","text":"Excalidraw"},{"type":"arrow","from":"a","to":"b"}]'
pulse excalidraw get --file "Доски/Проверка плагина.excalidraw"
pulse excalidraw export --file "Доски/Проверка плагина.excalidraw"     # PNG в Plugins/Excalidraw/Экспорт
```

Не оставляй пробную доску без спроса: удали её (`pulse files rm "Доски/Проверка плагина.excalidraw"`) или скажи
владельцу, что она есть.

## 5. Закрепи страницу (если владелец хочет)

```bash
pulse plugins pin excalidraw main
```

## 6. Расскажи владельцу

- **Доски** — меню «Плагины ▾ → Доски» ([/p/excalidraw/main](/p/excalidraw/main)): список досок и вход в редактор во
  всю вкладку (список досок, «+ Доска», чат с агентом справа). Любой файл `.excalidraw` открывается редактором прямо
  в «Файлах», новая доска — «Создать ▾ → Доска Excalidraw».
- **Автосохранение**: через 2 с после правки (не позже 10 с), статус «Сохраняю… / Сохранено · 14.05» в углу; закрытие
  вкладки с несохранённым — предупреждение, а копия правок остаётся в браузере и предлагается при следующем открытии.
- **Агенты**: `pulse excalidraw list | get | create | add | update | delete | export` — читают и рисуют на досках;
  правки появляются у владельца сразу («Агент изменил элементы — Показать»).
- **Чат у доски** — кнопка «Чат» в редакторе: обычный чат Пульса о файле доски, агент видит доску и выделение.
