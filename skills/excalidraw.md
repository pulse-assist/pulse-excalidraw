# Excalidraw — доски

Доска — файл `*.excalidraw` в «Файлах» (по умолчанию папка `Доски/`). Владелец рисует в редакторе: в «Файлах»
(доска открывается в панели просмотра) или во всю вкладку — [Доски](/p/excalidraw/main). Редактор сохраняет сам.
Рядом с доской — чат с агентом: сообщения оттуда приходят с припиской «— Доска: <путь> открыта в редакторе…;
выделено: …» — это и есть контекст: «эта схема», «выделенное», «сюда» — про эту доску и эти элементы.

## Команды

```bash
pulse excalidraw list                                         # известные доски; какие открыты сейчас и что выделено
pulse excalidraw get --file "Доски/План.excalidraw"           # описание словами + выделение у владельца
pulse excalidraw get --file "Доски/План.excalidraw" --format json   # элементы с id, координатами, размером
pulse excalidraw create --file "Доски/Схема.excalidraw" --elements '[…]'
pulse excalidraw add --file "Доски/План.excalidraw" --elements '[
  {"id": "a", "type": "rectangle", "text": "Заявка", "fill": "blue"},
  {"id": "b", "type": "diamond", "text": "Одобрена?"},
  {"id": "c", "type": "rectangle", "text": "Оплата", "fill": "green"},
  {"type": "arrow", "from": "a", "to": "b"},
  {"type": "arrow", "from": "b", "to": "c", "text": "да"}
]'
pulse excalidraw update --file "…" --elements '[{"id": "Xy12…", "text": "Новая подпись", "fill": "yellow"}]'
pulse excalidraw delete --file "…" --ids "Xy12…,Ab34…"
pulse excalidraw export --file "…" [--ids …] [--format png|svg] [--out "Доски/План.png"]
```

- **Без `--file`** команды берут доску, открытую сейчас в редакторе (если открыта одна). Пришёл запрос из чата
  у доски — путь есть в приписке к сообщению, передавай его в `--file`.
- **Сначала посмотри**, потом правь: `get` (описание и выделение), при правке — `--format json` (нужны id).
  Увидеть доску глазами — `export` (PNG без `--out` ляжет в `Plugins/Excalidraw/Экспорт/`, в ответе `disk_path`
  — открой его инструментом Read). Картинка серверная, упрощённая; точный вид — в редакторе.
- **Элементы `add`:** `rectangle`, `ellipse`, `diamond`, `sticky` (жёлтая заметка), `text`, `arrow`, `line`,
  `frame` (рамка-раздел: потом `"frame": "<id рамки>"` у элементов внутри). `text` у фигуры — подпись внутри неё.
  `id` в `add` — твоя метка, чтобы связать стрелку `from`/`to` с фигурами из той же команды; на доске id будут
  другие — они в ответе (`created`). Стрелки к существующим фигурам — их id из `get --format json`.
- **Раскладка.** Без `x`/`y` фигуры встают в ряд правее предыдущей (или под содержимым доски). Схему из
  нескольких рядов размечай сам: шаг ~260 по x и ~180 по y, фигура 200×100. Координаты растут вправо и вниз.
- **Цвета** словами: `fill` (заливка: blue, green, yellow, red, orange, violet, gray…), `color` (линия и текст).
  Красная заливка — только для «плохо / срочно».
- **Правки видны владельцу сразу:** открытый редактор подтягивает изменения и показывает «Агент изменил элементы
  — Показать». Его несохранённые правки не теряются: слияние идёт по элементам.
- **Не трогай без просьбы** чужие элементы и всю доску целиком: правь то, о чём просили (выделенное — в первую
  очередь). Не пересоздавай доску (`create --overwrite`) и не пиши файл доски через `pulse files write` — только
  командами выше: они сохраняют связи, картинки и правки владельца.
- Нужно вынести идеи с доски в задачи — `get`, затем `pulse cards create` по каждой (скилл «Работа с карточками»),
  а на доске можно подписать номер задачи (`update`).
- В ответе владельцу — что нарисовал или изменил, и ссылка на доску: `[План](/files?path=Доски/План.excalidraw)`
  (пробелы в пути — `%20`).
